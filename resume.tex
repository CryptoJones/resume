\item Architected and built a ground-up, ports-and-adapters reverse-engineering platform that wraps GayHydra's engine as a durable Rust core behind disposable protocol adapters (an MCP server for AI agents first), with the RE domain model serialized as a stable, zero-copy Cap'n Proto artifact --- the ``narrow waist'' that decouples every producer (analysis engine) from every consumer (UIs, agents, collaborators).
\item Locked 40+ architecture decisions with written rationale: bet on the slowest-moving layer (the RE domain model) and relocated volatility to sheddable edges, so the analysis engine, the wire protocol, and the agent adapter can each be replaced without touching the core.
\item Designed a four-pass identity-anchored matcher (exact signature, architecture-independent string/import/call anchors, reciprocal-best fuzzy, and call-graph propagation) that carries analyst annotations across re-analysis, recompilation, and \emph{cross-architecture} rebuilds (x86-64, aarch64, and 32-bit) under a hard ``zero silent mis-attachment'' invariant --- enforced by a ratcheted release gate over an 11-class binary corpus, so low-confidence matches degrade to flagged-for-review, never a wrong write.
\item Built the engine as a sandboxed gRPC service --- a warm co-resident GayHydra runtime (roughly 3x faster than cold per-call analysis) with a worker pool and cold-subprocess fallback, running in a no-egress container (no network namespace; gRPC over a bind-mounted Unix socket) behind a seam-by-seam threat model, a bounds-checked artifact loader, and keyless Sigstore signing of the CLI and image --- with the major bets de-risked by empirical spikes before building.
\end{rSubsection}

\begin{rSubsection}{\href{https://github.com/CryptoJones/omind}{omind}}{Python}{}{}
